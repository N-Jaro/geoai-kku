### D1. Site Scouting (≈15 นาที) — **ทำก่อนเห็นผลโมเดลเสมอ**

เปิด Google Earth หรือ Google Maps (มุมมองดาวเทียม) ใส่พิกัดทีละจุด ซูมให้เห็นพื้นที่ประมาณ **2 × 2 กม.** (เท่ากับหน้าต่างภาพที่แล็บจะดึง) แล้วกรอกว่า **คุณ** เห็นว่าพื้นที่ส่วนใหญ่เป็นอะไร เลือกจากรายการ: `rice paddy field` · `sugarcane field` · `forest` · `water body` · `urban area with buildings` · `bare soil`

| จุด | พิกัด (lat, lon) | คลาสที่ฉันเห็นเป็นส่วนใหญ่ | สิ่งที่เห็นเป็นหลักฐาน | มีหลายคลาสปนกันไหม | ความมั่นใจ (1–5) |
|---|---|---|---|---|---|
| มข. (วิทยาเขตหลัก) | 16.472, 102.823 | | | | |
| บึงแก่นนคร | 16.420, 102.833 | | | | |
| เขื่อนอุบลรัตน์ | 16.775, 102.620 | | | | |
| ภูเวียง (พื้นที่ป่า) | 16.690, 102.320 | | | | |
| ที่ราบลุ่มน้ำชี (นาข้าว) | 16.090, 102.700 | | | | |

> พิกัดเป็นค่าโดยประมาณจากอาจารย์ — **ถ้าตำแหน่งนั้นไม่ใช่อย่างที่ชื่อบอก ให้เขียนสิ่งที่คุณเห็นจริง** ไม่ใช่สิ่งที่ชื่อบอก ในแล็บเราจะกรอกคำตอบนี้ลงเซลล์ `truth` แล้ว **ล็อกก่อนรันโมเดล** เพื่อไม่ให้ปรับคำตอบให้เข้ากับโมเดล
