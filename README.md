## กฎของวิชา (ย่อ)

- **Prompt → Review → Execute → Verify on map** ทุกแล็บ
- **Explain This** — อธิบายโค้ดเป็นภาษาไทยก่อนรัน
- **Prompt Log** — บันทึกคำสั่งที่ใช้กับ AI แนบท้าย notebook ทุกสัปดาห์
- แต่ละสัปดาห์ commit งานเข้า repo ของตนเอง (ข้อความ commit เช่น `week01: lab + prompt log`)
