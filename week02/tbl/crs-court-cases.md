## คดีที่ 1 — "ชั้นข้อมูลหายไปจากแผนที่"

**เรื่องย่อ:** เจ้าหน้าที่ ทสจ. ขอนแก่นซ้อนขอบเขตอำเภอ (ไฟล์ GeoJSON) กับภาพ Sentinel-2 เพื่อทำแผนที่ประกอบรายงาน เขียนโค้ดพลอตสองชั้นบนแกนเดียวกัน ภาพขึ้นปกติ แต่ **ขอบเขตอำเภอไม่ปรากฏบนภาพเลย** — ซูมแล้วก็ไม่เจอ

**หลักฐาน**

```python
amphoe.crs            # <Geographic 2D CRS: EPSG:4326>
amphoe.total_bounds   # [102.7060  16.3223  102.9605  16.4875]

s2.rio.crs            # EPSG:32648
s2.rio.bounds()       # (263550.0, 1813040.0, 273670.0, 1822880.0)

fig, ax = plt.subplots()
s2.plot.imshow(ax=ax)
amphoe.boundary.plot(ax=ax)      # ไม่มี error
plt.show()                       # แกนแสดงช่วง 263,550 ถึง 273,670 — ไม่เห็นขอบเขตอำเภอ
```

**คำถามของศาล**
1. ตัวเลขสองชุดบอกอะไรเกี่ยวกับ "หน่วย" ของสองชั้น
2. ขอบเขตอำเภอไปอยู่ที่ไหนบนแกนของภาพ (ลองประมาณ)
3. แก้อย่างไร และจะตรวจได้อย่างไรว่าชั้นสองซ้อนกันแล้ว

## คดีที่ 2 — "วงกลม 500 เมตร ครอบทั้งประเทศ"

**เรื่องย่อ:** นักศึกษาฝึกงานได้รับมอบหมายให้ทำบัฟเฟอร์รัศมี 500 เมตรรอบสถานีวัดน้ำ ข้อมูลสถานีอ่านจากไฟล์ CSV แล้วแปลงเป็นจุด โค้ดรันผ่านเรียบร้อย แต่เมื่อพลอต **วงกลมใหญ่มากจนมองไม่เห็นจุดอื่น**

**หลักฐาน**

```python
stations = gpd.GeoDataFrame(df, geometry=gpd.points_from_xy(df.lon, df.lat), crs="EPSG:4326")
stations.geometry.iloc[0]                      # POINT (102.823 16.472)

buf = stations.buffer(500)
buf.total_bounds                               # [-397.177  -483.528   602.823   516.472]
# UserWarning: Geometry is in a geographic CRS. Results from 'buffer' are likely incorrect.
```

**คำถามของศาล**
1. `500` ในโค้ดนี้มีหน่วยเป็นอะไร ตัวเลขใน `total_bounds` บอกอะไร
2. ถ้าแก้โดยเปลี่ยน `500` เป็น `0.0045` จะ "ถูก" ไหม เพราะอะไร
3. ลำดับการแก้ที่ถูกคืออะไร และจะตรวจได้อย่างไรว่าบัฟเฟอร์ใหม่มีรัศมี 500 เมตรจริง (ใบ้: พื้นที่วงกลมคือ πr²)

## คดีที่ 3 — "จุดสำรวจหายไปจากแผนที่เมื่อแปลงพิกัด"

**เรื่องย่อ:** ทีมสำรวจส่งไฟล์ CSV จุดตรวจวัดมา 2 คอลัมน์ `lat`, `lon` นักวิเคราะห์สร้างจุดแล้วแปลงเป็น UTM เพื่อนำไปคำนวณระยะ แต่ **ผลลัพธ์เป็น `inf` ทุกตัว** และพลอตแล้วไม่เห็นจุดเลย

**หลักฐาน**

```python
df.head()
#      name   lat      lon
# 0     มข.  16.472  102.823
# 1  บึงแก่นนคร  16.420  102.833

pts = gpd.GeoDataFrame(df, geometry=gpd.points_from_xy(df.lat, df.lon), crs="EPSG:4326")
pts.geometry.iloc[0]                  # POINT (16.472 102.823)
pts.to_crs("EPSG:32648").total_bounds # [inf inf inf inf]
```

**คำถามของศาล**
1. ใน `POINT (16.472 102.823)` ตัวเลขตัวแรกคือแกนอะไร ตัวที่สองคือแกนอะไร ตำแหน่งนี้อยู่ที่ไหนบนโลก (ใบ้: ละติจูดมีค่าได้ในช่วงใด)
2. ทำไม GeoPandas ไม่ error ตอนสร้างจุด แต่ไป "พัง" ตอน `to_crs`
3. แก้อย่างไร และตรวจอย่างไรว่าจุดอยู่ในขอนแก่นจริง

## คดีที่ 4 — "แปลงที่ดินเลื่อนไปประมาณ 700 เมตร"

**เรื่องย่อ:** ได้ข้อมูลแปลงที่ดินจากหน่วยงานรัฐ เป็น Shapefile มาจากระบบแผนที่เก่า นักวิเคราะห์เปิดไม่ได้ CRS จึงเดาว่าเป็น UTM โซน 48 ของ WGS 84 ซ้อนกับภาพ Sentinel-2 — **ขอบแปลงไม่ตรงกับถนนและคันนาในภาพ เลื่อนไปทางตะวันออกเฉียงใต้ประมาณ 700 เมตร** (เลื่อนเท่ากันทุกแปลง ไม่ได้บิดหมุน)

**หลักฐาน**

```python
os.listdir("parcels")          # ['parcels.shp', 'parcels.shx', 'parcels.dbf']   <- ไม่มี .prj
parcels = gpd.read_file("parcels/parcels.shp")
parcels.crs                    # None
parcels.total_bounds           # [ 267520.  1816920.   268810.  1817950.]

parcels = parcels.set_crs("EPSG:32648")      # "เดา" ว่าเป็น UTM 48N ของ WGS 84
# ซ้อนกับภาพ Sentinel-2 -> เลื่อนทิศตะวันออกเฉียงใต้ ~700 ม. เท่ากันทุกแปลง
```
เอกสารกำกับของหน่วยงานเขียนไว้ว่า "ระบบพิกัด UTM โซน 48 ตามแผนที่ภูมิประเทศมาตราส่วน 1:50,000 (Indian 1975)"

**คำถามของศาล**
1. ตัวเลขใน `total_bounds` บอกอะไรเรื่องหน่วย และทำไมเดาได้ว่าเป็น UTM โซนไหน
2. ทำไม "ชื่อโซนถูก" แต่ตำแหน่งยังผิด
3. ลำดับการแก้ที่ถูกต้องคืออะไร (ใช้ `set_crs` กับ `to_crs` อย่างละกี่ครั้ง ด้วยรหัสอะไร) และจะตรวจได้อย่างไร (ใบ้: เทียบกับรูปทรงที่เห็นชัดในภาพ เช่น ถนน คันนา)

## คดีโบนัส (ทีมที่เสร็จก่อน) — "ประเภทที่ดินที่ไม่มีอยู่จริง"

**เรื่องย่อ:** หลังลดความละเอียดแผนที่ประเภทที่ดิน (1 = น้ำ, 2 = ดินโล่ง, 3 = พืชโปร่ง, 4 = พืชหนาแน่น) ผู้ใช้ปลายทางพบว่า **มีแถบ "ดินโล่ง" และ "พืชโปร่ง" ล้อมรอบบึงน้ำทุกแห่ง** ทั้งที่ภาพจริงเป็นน้ำติดกับป่าชายเลน

**หลักฐาน**

```python
lulc_100 = lulc.rio.reproject(lulc.rio.crs, resolution=100, resampling=Resampling.bilinear)
sorted(set(np.round(lulc_100.values, 1).ravel()))[:8]
# [1.0, 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7]   <- ค่าที่ไม่ใช่จำนวนเต็มเต็มไปหมด
```

**คำถามของศาล:** สาเหตุคืออะไร · ควรแก้ด้วยวิธีใด · ถ้าอยากได้ "สัดส่วนพื้นที่น้ำในเซลล์ 100 ม." ควรทำอย่างไร (ไม่ใช่ `bilinear` กับรหัสประเภท)
