# เทมเพลต Prompt ประจำวิชา GeoAI

โครงสร้างนี้ใช้ทุกแล็บ เพื่อให้ AI ได้ข้อมูลเชิงพื้นที่ครบและโค้ดที่ได้ตรวจสอบง่าย

```
[บทบาท]    คุณคือผู้ช่วยเขียน Python สำหรับงานภูมิสารสนเทศ ใช้ Google Colab
[เป้าหมาย] <ต้องการผลลัพธ์อะไร เช่น "ทำแผนที่ภาพสีจริงของพื้นที่นี้">
[ข้อมูลเข้า] <ไฟล์/แหล่งข้อมูล, ชื่อคอลัมน์, ชนิดข้อมูล>
[ข้อกำหนดเชิงพื้นที่]
  - CRS: <เช่น EPSG:4326 / EPSG:32648>
  - ความละเอียด/หน่วย: <เช่น 10 m>
  - ขอบเขตพื้นที่ (bbox): <west, south, east, north>
[ไลบรารีที่ใช้ได้] <เช่น geopandas, rasterio, matplotlib — ห้ามใช้ตัวอื่นถ้าไม่จำเป็น>
[รูปแบบผลลัพธ์] <ตาราง/ภาพ/ไฟล์ GeoTIFF + ชื่อไฟล์>
[ข้อจำกัด] เขียนทีละเซลล์ สั้น มีคอมเมนต์ภาษาไทย พิมพ์ shape / CRS / ช่วงค่า หลังทุกขั้นสำคัญ
```

## ตัวอย่าง: แย่ vs ดี

**แย่:** "เขียนโค้ดแสดงภาพดาวเทียมขอนแก่น"

**ดี:**

```
คุณคือผู้ช่วยเขียน Python สำหรับ Google Colab
เป้าหมาย: แสดงภาพสีจริง (RGB) Sentinel-2 L2A ของพื้นที่รอบมหาวิทยาลัยขอนแก่น
ข้อมูล: STAC Earth Search (https://earth-search.aws.element84.com/v1) collection sentinel-2-l2a, cloud cover < 10%, ช่วง 2026-01-01 ถึง 2026-03-31
พื้นที่: จุดกลาง lat 16.472, lon 102.823 กรอบ 2.24 km x 2.24 km
CRS: อ่านจากไฟล์ แล้วแปลง bbox จาก EPSG:4326 ให้ตรง CRS ของภาพ
ไลบรารี: pystac-client, rasterio, matplotlib
ผลลัพธ์: ภาพ 1 ภาพ ใส่ชื่อวันที่ถ่ายและ cloud cover ในหัวภาพ
ข้อจำกัด: เขียนเป็นเซลล์สั้น ๆ คอมเมนต์ไทย พิมพ์ shape, CRS และช่วงค่าพิกเซลหลังอ่านภาพ
```

## เช็กลิสต์ก่อนกด Enter

- [ ] ระบุ CRS ชัดเจนหรือยัง
- [ ] ระบุหน่วยและความละเอียดหรือยัง
- [ ] ระบุชื่อคอลัมน์/ไฟล์ตรงกับของจริงหรือยัง
- [ ] ระบุรูปแบบผลลัพธ์หรือยัง
- [ ] ขอให้พิมพ์ตรวจ shape / CRS / ช่วงค่าหรือยัง
